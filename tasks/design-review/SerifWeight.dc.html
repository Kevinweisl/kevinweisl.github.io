Young Serif 沒有粗體

字體

這條不是品味問題，是 CSS 在說謊。Young Serif 只出 400 一個字重，而 body 設了 font-synthesis-weight: none 禁止瀏覽器造假。所以 serif 元素上每一個 font-semibold 與 font-bold 都是空宣告。

400 Young Serif 唯一的字重 5 個元件寫了無效的字重 0 實際生效的
現況左邊是 CSS，右邊是螢幕
Hero h1 · font-serif font-bold Kevin Wei
Section h2 · font-serif font-semibold Selected Publications
NoteCard h3 · font-serif font-semibold ccClub 十年記・下
三行宣告了 700、600、600，螢幕上三行都是 400。字重完全沒有參與階層。
  • 階層其實只剩尺寸在扛，但 CSS 讀起來像有三段字重
  • 之後有人換字體，這些宣告會突然「醒過來」，版面無預警改變
  • font-synthesis-weight: none 是對的，不該拿掉來換假粗體
提案刪掉宣告，階層交給尺寸與留白
Hero h1 · font-serif Kevin Wei
Section h2 · font-serif Selected Publications
NoteCard h3 · font-serif ccClub 十年記・下
畫面完全一樣，因為本來就是這樣渲染的。差別是 CSS 現在說的是實話，而且 hero 加大到 34px 拉開了與區塊標題的距離。
  • 純刪除，零視覺風險 —— 現在的畫面就是刪除後的畫面
  • Young Serif 400 本來就比一般 serif 重，不需要再加粗
  • 另外兩條路：換一個有多字重的展示字體，或標題改用 Albert Sans 600、Young Serif 只留給 hero 的名字
